Kebijakan Privasi CoffeePOS

Aplikasi Kasir Coffee Shop Offline

Terakhir diperbarui: 5 Juli 2026

1. Pengantar

Selamat datang di CoffeePOS. Kami menghargai privasi pengguna dan berkomitmen untuk melindungi informasi yang digunakan dalam aplikasi ini. Kebijakan Privasi ini menjelaskan bagaimana CoffeePOS mengelola data saat Anda menggunakan aplikasi.

2. Data yang Dikumpulkan

CoffeePOS dirancang sebagai aplikasi kasir yang dapat digunakan secara offline. Sebagian besar data disimpan langsung pada perangkat pengguna.

  • Nama toko dan pengaturan aplikasi.
  • Data produk atau menu.
  • Data transaksi penjualan.
  • Data kategori produk.
  • Data laporan penjualan.

Data tersebut tidak dikirim ke server kami dan tetap berada pada perangkat pengguna.

3. Penggunaan Data

Data digunakan untuk:

  • Menjalankan fungsi kasir.
  • Mencatat transaksi penjualan.
  • Mengelola produk dan kategori.
  • Menyusun laporan penjualan.
  • Menyimpan pengaturan aplikasi.

4. Iklan dan Layanan Pihak Ketiga

CoffeePOS dapat menggunakan layanan pihak ketiga untuk meningkatkan kualitas layanan.

Google AdMob

Aplikasi dapat menampilkan iklan melalui Google AdMob. AdMob dapat mengumpulkan informasi tertentu seperti Advertising ID dan informasi perangkat sesuai dengan kebijakan Google.

Kebijakan Privasi Google:
https://policies.google.com/privacy

Firebase Crashlytics (Jika Digunakan)

Firebase Crashlytics dapat digunakan untuk membantu mendeteksi kesalahan aplikasi (crash) sehingga kami dapat meningkatkan stabilitas aplikasi.

5. Penyimpanan Data

Sebagian besar data CoffeePOS disimpan secara lokal pada perangkat pengguna. Pengguna bertanggung jawab untuk melakukan pencadangan (backup) data apabila diperlukan.

6. Keamanan Data

Kami berupaya menjaga keamanan aplikasi dan data yang tersimpan. Namun, tidak ada metode penyimpanan elektronik yang dapat dijamin 100% aman.

7. Hak Pengguna

  • Menghapus data aplikasi kapan saja.
  • Menghapus aplikasi dari perangkat.
  • Mengelola izin aplikasi melalui pengaturan Android.

8. Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui sewaktu-waktu untuk menyesuaikan perkembangan aplikasi maupun perubahan peraturan yang berlaku.
