Kebijakan Privasi Rapor Guru Pintar

Aplikasi Manajemen Nilai dan Kehadiran Siswa

Terakhir diperbarui: 1 Agustus 2026

1. Pengantar

Selamat datang di Rapor Guru Pintar. Kami sangat menghargai privasi Anda dan berkomitmen untuk melindungi data serta informasi yang dikelola melalui aplikasi ini. Kebijakan Privasi ini menjelaskan bagaimana Rapor Guru Pintar mengelola data siswa, nilai, dan rekap kehadiran saat Anda menggunakan aplikasi.

2. Data yang Dikumpulkan

Rapor Guru Pintar dirancang untuk membantu para pendidik dalam mengelola administrasi kelas. Data yang diinputkan oleh pengguna meliputi:

  • Data identitas siswa (Nama, Nomor Induk/NIS, Kelas).
  • Data rekap kehadiran dan presensi bulanan siswa.
  • Data nilai tugas, ujian, dan catatan evaluasi akademik.
  • Data mata pelajaran dan pengaturan bobot nilai.

Sebagian besar data ini disimpan langsung secara lokal pada perangkat Anda dan tidak dibagikan ke pihak ketiga tanpa persetujuan Anda.

3. Penggunaan Data

Seluruh data yang dimasukkan ke dalam aplikasi digunakan semata-mata untuk:

  • Mencatat dan mengelola daftar hadir (presensi) siswa.
  • Mengalkulasi dan memproses nilai akademik siswa secara otomatis.
  • Menyusun dan mencetak laporan hasil belajar (rapor) siswa.
  • Menyimpan rekam jejak perkembangan akademik siswa di kelas.

4. Layanan Pihak Ketiga

Untuk mendukung operasional dan pengembangan aplikasi, Rapor Guru Pintar dapat memanfaatkan beberapa layanan pihak ketiga berikut:

Google AdMob

Aplikasi dapat menampilkan iklan untuk mendukung pengembangan fitur gratis. AdMob dapat mengumpulkan informasi anonim seperti Advertising ID dan spesifikasi perangkat sesuai kebijakan Google.

Kebijakan Privasi Google:
https://policies.google.com/privacy

Firebase Crashlytics / Analytics

Kami dapat mengumpulkan data teknis anonim jika terjadi kesalahan (crash) pada aplikasi guna membantu perbaikan bug dan peningkatan stabilitas.

5. Penyimpanan dan Pencadangan Data

Data tersimpan secara lokal pada penyimpanan internal perangkat Anda. Untuk mencegah kehilangan data akademik siswa akibat kerusakan atau pergantian perangkat, pengguna disarankan untuk melakukan pencadangan (backup) data secara berkala melalui fitur yang tersedia.

6. Keamanan Data

Kami berupaya keras untuk menjaga keamanan aplikasi dari akses yang tidak sah. Walaupun demikian, pengguna diharapkan tetap menjaga keamanan perangkat pribadi (misal: memberikan PIN/Sandi pada perangkat) untuk melindungi data nilai siswa dari pihak lain.

7. Hak Pengguna

  • Mengubah atau menghapus data siswa, nilai, dan kehadiran kapan saja.
  • Melakukan ekspor data nilai/rapor ke format lain (jika fitur tersedia).
  • Menghapus seluruh data aplikasi dengan cara menghapus data lewat Pengaturan Android atau menginstal ulang aplikasi.

8. Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat kami perbarui sewaktu-waktu sesuai dengan penambahan fitur aplikasi maupun regulasi pendidikan yang berlaku.
