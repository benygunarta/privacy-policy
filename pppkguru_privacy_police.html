Kebijakan Privasi PPPK Guru 2026

Komitmen penuh dalam melindungi integritas data pribadi dan privasi para tenaga pendidik Indonesia.

Terakhir Diperbarui: 29 Mei 2026  |  Versi 1.0 (Kepatuhan UU PDP)

Pengantar

Selamat datang di Aplikasi PPPK Guru 2026. Kami sangat memahami tanggung jawab besar Anda sebagai calon aparatur sipil negara. Oleh karena itu, jaminan keamanan data pribadi Anda adalah prioritas mutlak sistem kami. Kebijakan ini menjelaskan transparansi pengelolaan data Anda sesuai amanat hukum yang berlaku.

Data yang Kami Kumpulkan

Untuk menunjang performa simulasi ujian CAT agar seakurat mungkin, aplikasi memproses beberapa data berikut:

Profil Identitas

Nama lengkap, email aktif, formasi guru pilihan, serta instansi daerah asal pendaftaran.

Progres & Skor

Riwayat pengerjaan kuis, jawaban soal, nilai akhir uji kompetensi, serta statistik durasi belajar.

Informasi Teknis

Model perangkat seluler, versi sistem operasi (Android/iOS), dan data kestabilan jaringan.

Penggunaan Informasi Anda

Data Anda murni diolah di dalam ekosistem aplikasi untuk keperluan esensial berikut:

  • Menyajikan grafik perkembangan kompetensi dan memprediksi titik kelulusan ujian Anda.
  • Mengirimkan notifikasi darurat terkait jadwal pendaftaran PPPK BKN atau materi soal terbaru.
  • Menganalisis sistem eror (*crash logs*) demi menjaga kestabilan aplikasi saat simulasi berjalan.

Transparansi Pihak Ketiga

Kami tidak pernah menjual data pribadi Anda. Penggunaan mitra eksternal dilakukan secara terbatas hanya demi kelancaran teknis aplikasi:

Layanan Mitra Kategori Data Tujuan Operasional
Google Firebase ID Perangkat & Log Crash Mengirimkan notifikasi dan melacak kegagalan sistem pengujian.
Layanan Hosting Server Data Akun Terenkripsi Sinkronisasi cadangan progres belajar secara cloud.

Hak Anda & Keamanan Data

Sesuai dengan UU Perlindungan Data Pribadi (UU PDP) No. 27 Tahun 2022, Anda memegang kontrol penuh atas data Anda sendiri:

  • Hak Akses & Koreksi: Anda bebas mengubah profil dan formasi guru kapan pun di dalam menu Pengaturan.
  • Hak Penghapusan (Hak untuk Dilupakan): Anda dapat meminta penghapusan akun beserta seluruh riwayat nilai simulasi secara permanen dari server kami.
